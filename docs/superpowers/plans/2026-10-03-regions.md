# Regions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move everything Toronto- and Canada-specific into one region file per market, ship Toronto (unchanged behaviour) and Abu Dhabi, and keep regions' data apart.

**Architecture:** `config/sources.json` names the active region; `config/regions/<name>.json` holds every regional setting. Tracker.Core loads it into a `Region` object and builds the scope, salary and citizenship patterns from it. The Archiver layers the region file into its configuration. Manifests and pasted files record their region, and a rebuild reads only the active region's data. The API passes region labels and formats to the dashboard through `/api/meta`.

**Tech Stack:** .NET 10, EF Core 10 + Npgsql, xUnit + Testcontainers, React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-03-regions-design.md`

## Global Constraints

- Compatibility with `"Region": "toronto"` is a hard requirement (spec guarantees 1–5). Every existing test keeps its assertions except where a task names the change (labels and report wording only, never data).
- Secrets stay in user-secrets or environment variables. Never read, print or commit `.env`, `config/profile.json`, `config/cv.json`, `data/` contents or `.artifacts/`.
- Never call Adzuna and never run the Archiver against the network. Calling the public Greenhouse, Lever and Ashby board endpoints is allowed in Task 1 only, to choose Abu Dhabi boards.
- Never write to the owner's live database `tracker`. The compatibility check uses a scratch database in the same container.
- No `ApplicationsDb` change, no `tracker.json` format change.
- 0 build warnings. Commit per task, with the session's attribution lines.
- Region JSON uses PascalCase names like `processor.json`, allows `//` comments, and rejects unknown members.

## Review Focus

1. **Toronto pattern equivalence.** The patterns generated from `toronto.json` must be character-for-character the old hand-written ones (alternation order and case flags included). Pinned by the pattern-string tests in Task 2 and by the full compatibility check in Task 8.
2. **A typo in a region file** ("Placess", a misspelt section) must be a config error naming the member, not silently ignored. Test in Task 1.
3. **A mixed archive** (Toronto and Abu Dhabi runs, plus pasted files from both) must rebuild only the active region and say what it skipped. Test in Task 3.
4. **AED salary spellings** that are common in UAE postings must parse:
   - "AED25,000-AED35,000/month"
   - "AED 25k - 35k monthly"
   - "Salary: 30,000 - 40,000 AED per month"
   
   Test in Task 2.
5. **Dashboard before `/api/meta` loads.** It formats with the defaults (en-CA, America/Toronto) and must not crash. After meta loads it switches to the region's format. Test in Task 7.

```csharp
using System.Globalization;
using System.Text.Json;
using System.Text.Json.Serialization;
using System.Text.RegularExpressions;

namespace Tracker.Configuration;

// One job market: everything that differs between Toronto and Abu Dhabi (ADR 0015). config/sources.json names the
// active one; the file is config/regions/<name>.json. List entries marked "pattern" are regular-expression fragments
// matched as whole words (plain words work as written; escape a literal dot as \.).
public sealed class Region
{
    public string Name { get; set; } = "";
    public string Title { get; set; } = "";
    public string LocalLabel { get; set; } = "";
    public string RemoteLabel { get; set; } = "";
    public string CountryCode { get; set; } = "";
    public List<string> CountryNames { get; set; } = [];
    public string Culture { get; set; } = "";
    public string TimeZone { get; set; } = "";
    public RegionMarkers InCountry { get; set; } = new();
    public RegionMarkers Foreign { get; set; } = new();
    public RegionLocal Local { get; set; } = new();
    public RegionSalary Salary { get; set; } = new();
    public List<string> CitizenshipPatterns { get; set; } = [];
    public RegionAdzuna? Adzuna { get; set; }
    public List<RegionBoard> Boards { get; set; } = [];
    public Dictionary<string, string> CompanyNames { get; set; } = new(StringComparer.OrdinalIgnoreCase);
    public JobBankOptions? JobBank { get; set; }

    [JsonIgnore] public CultureInfo CultureInfo => CultureInfo.GetCultureInfo(Culture);

    // Board files only carry a slug; prefer the configured display name, else capitalize the slug.
    public string CompanyName(string slug) =>
        CompanyNames.TryGetValue(slug, out var name) ? name : slug.Length == 0 ? slug : char.ToUpperInvariant(slug[0]) + slug[1..];
}

public sealed class RegionMarkers
{
    public List<string> Words { get; set; } = []; // patterns, case-insensitive
    public List<string> Codes { get; set; } = []; // literal, case-sensitive, after "," (or "-" for in-country codes)
}

public sealed class RegionLocal
{
    public Dictionary<string, string> Places { get; set; } = []; // name as written → place shown
    public List<string> NeedsCountryContext { get; set; } = [];
}

public sealed class RegionSalary
{
    public string Currency { get; set; } = "";
    public string MoneyPrefix { get; set; } = "";
    public List<string> Signs { get; set; } = [];             // literal, before an amount (besides the code)
    public List<string> ShortMarks { get; set; } = [];        // literal, after an amount (besides the code)
    public List<string> ForeignCurrencies { get; set; } = [];
    public List<string> ForeignSigns { get; set; } = [];
    public List<string> ForeignShortMarks { get; set; } = [];
    public string BareDollar { get; set; } = "ambiguous";     // or "foreign"
    public bool CodeAfterAmount { get; set; }                  // "25,000 - 35,000 AED" with no sign before
    public bool MonthlyIsSalary { get; set; }
    public List<string> ContextWords { get; set; } = [];       // patterns
    public List<string> ForeignContextWords { get; set; } = []; // patterns
    public List<string> ForeignContextCodes { get; set; } = []; // literal, case-sensitive
    public decimal YearlyMin { get; set; }
    public decimal YearlyMax { get; set; }
}

public sealed class RegionAdzuna
{
    public string Country { get; set; } = "";
    public string Where { get; set; } = "";
    public int DistanceKm { get; set; }
}

public sealed class RegionBoard
{
    public string Ats { get; set; } = "";
    public string Slug { get; set; } = "";
}

public static class Regions
{
    // Collections and pasted files from before regions existed were all Toronto.
    public const string Legacy = "toronto";

    private static readonly JsonSerializerOptions Json = new()
    {
        PropertyNameCaseInsensitive = true,
        ReadCommentHandling = JsonCommentHandling.Skip,
        AllowTrailingCommas = true,
        UnmappedMemberHandling = JsonUnmappedMemberHandling.Disallow,
    };

    public static string ActiveName(string repoRoot)
    {
        var path = Path.Combine(repoRoot, "config", "sources.json");
        using var doc = JsonDocument.Parse(File.ReadAllText(path), new JsonDocumentOptions { CommentHandling = JsonCommentHandling.Skip });
        return doc.RootElement.TryGetProperty("Region", out var name) && name.ValueKind == JsonValueKind.String && name.GetString()!.Trim().Length > 0
            ? name.GetString()!.Trim()
            : throw new InvalidDataException($"{path}: add \"Region\": \"<name>\" naming a file in config/regions/ (for example \"toronto\").");
    }

    public static Region Load(string repoRoot, string? name = null)
    {
        name ??= ActiveName(repoRoot);
        var folder = Path.Combine(repoRoot, "config", "regions");
        var path = Path.Combine(folder, $"{name}.json");
        if (!File.Exists(path))
        {
            var known = Directory.Exists(folder) ? Directory.GetFiles(folder, "*.json").Select(Path.GetFileNameWithoutExtension).Order() : [];
            throw new InvalidDataException($"Region '{name}' has no file {path}. Available: {string.Join(", ", known)}.");
        }
        return LoadFile(path);
    }

    public static Region LoadFile(string path)
    {
        Region region;
        try
        {
            region = JsonSerializer.Deserialize<Region>(File.ReadAllText(path), Json) ?? throw new InvalidDataException($"{path} is empty.");
        }
        catch (JsonException ex)
        {
            throw new InvalidDataException($"{path}: {ex.Message}", ex);
        }
        region.CompanyNames = new Dictionary<string, string>(region.CompanyNames, StringComparer.OrdinalIgnoreCase);
        var problems = Validate(region);
        if (problems.Count > 0) throw new InvalidDataException($"{path}: {string.Join(" ", problems)}");
        return region;
    }

    private static List<string> Validate(Region r)
    {
        var p = new List<string>();
        void Required(string value, string member) { if (string.IsNullOrWhiteSpace(value)) p.Add($"{member} is required."); }
        Required(r.Name, "Name"); Required(r.Title, "Title"); Required(r.LocalLabel, "LocalLabel"); Required(r.RemoteLabel, "RemoteLabel");
        Required(r.CountryCode, "CountryCode"); Required(r.Culture, "Culture"); Required(r.TimeZone, "TimeZone");
        Required(r.Salary.Currency, "Salary.Currency");
        if (r.Local.Places.Count == 0) p.Add("Local.Places must list at least one place.");
        if (r.Boards.Count == 0) p.Add("Boards must list at least one job board.");
        if (r.Salary.YearlyMin <= 0 || r.Salary.YearlyMin >= r.Salary.YearlyMax) p.Add("Salary.YearlyMin must be above 0 and below Salary.YearlyMax.");
        if (r.Salary.BareDollar is not ("ambiguous" or "foreign")) p.Add("Salary.BareDollar must be \"ambiguous\" or \"foreign\".");
        if (r.Culture.Length > 0)
            try { _ = CultureInfo.GetCultureInfo(r.Culture, predefinedOnly: true); } catch (CultureNotFoundException) { p.Add($"Culture '{r.Culture}' is not a known culture."); }
        if (r.TimeZone.Length > 0)
            try { _ = TimeZoneInfo.FindSystemTimeZoneById(r.TimeZone); } catch (TimeZoneNotFoundException) { p.Add($"TimeZone '{r.TimeZone}' is not a known time zone."); }
        foreach (var (list, member) in new[] { (r.CitizenshipPatterns, "CitizenshipPatterns"), (r.InCountry.Words, "InCountry.Words"),
            (r.Foreign.Words, "Foreign.Words"), (r.Salary.ContextWords, "Salary.ContextWords"), (r.Salary.ForeignContextWords, "Salary.ForeignContextWords") })
            foreach (var pattern in list)
                try { _ = new Regex(pattern); } catch (ArgumentException) { p.Add($"{member}: '{pattern}' is not a valid pattern."); }
        return p;
    }
}
```

```csharp
internal static class RegionPatterns
{
    public const string Never = "(?!)";

    // \b(?:a|b)\b over pattern fragments, as the hand-written regexes did.
    public static string Words(IReadOnlyList<string> patterns) =>
        patterns.Count == 0 ? Never : $@"\b(?:{string.Join('|', patterns)})\b";

    public static string Codes(string separators, IReadOnlyList<string> codes) =>
        codes.Count == 0 ? Never : $@"{separators}\s*(?:{string.Join('|', codes.Select(Regex.Escape))})\b";

    // Words (case-insensitive) or ", CODE" (case-sensitive), in one pattern compiled with IgnoreCase.
    public static string WordsOrCodes(IReadOnlyList<string> words, IReadOnlyList<string> codes)
    {
        var parts = new List<string>();
        if (words.Count > 0) parts.Add($@"\b(?:{string.Join('|', words)})\b");
        if (codes.Count > 0) parts.Add($@",\s*(?-i:{string.Join('|', codes.Select(Regex.Escape))})\b");
        return parts.Count == 0 ? Never : string.Join('|', parts);
    }
}
```

```csharp
public enum SalaryPeriod { Year, Hour, Month }

public sealed record SalaryRange(decimal Min, decimal Max, SalaryPeriod Period)
{
    public const decimal HoursPerYear = 2080;

    public decimal YearlyMin => Yearly(Min);
    public decimal YearlyMax => Yearly(Max);
    public decimal YearlyMidpoint => (YearlyMin + YearlyMax) / 2;

    // Guards against parse errors and non-salary amounts (stipends, bonuses). Bounds come from the region.
    public bool IsPlausibleWithin(decimal yearlyMin, decimal yearlyMax) => Min <= Max && YearlyMin >= yearlyMin && YearlyMax <= yearlyMax;
```
